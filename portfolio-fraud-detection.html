Canadian Banking Fraud Detection Dashboard

An end-to-end fraud intelligence platform built on 1.3M+ Canadian banking transactions (2019–2020). The dashboard spans 6 interactive pages: a Home landing page, Executive Overview with province-level KPIs, Fraud Trends with day-of-week heatmaps and rolling 30-day charts, Geo Analysis with a province map, a Transaction Drill-Through page for individual case investigation, and an ML Model Performance page showcasing an XGBoost pipeline achieving 96.42% recall and $966K net benefit over a no-model baseline.

Key features include fraud score gauges, SHAP-based feature importance, PR-AUC model comparison (Logistic Regression vs Random Forest vs XGBoost), and risk tier breakdowns — all designed to support real-world fraud analyst and executive decision-making workflows.
