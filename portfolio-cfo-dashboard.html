CFO Financial KPI Dashboard

A production-grade financial analytics platform built for a fictional Canadian B2B company (NorthStar Analytics Inc.), combining data engineering, machine learning, and business intelligence to simulate a real CFO reporting system. The project covers the complete analytics stack: synthetic data generation, Apache Airflow ETL pipeline, PostgreSQL star schema, three ML models, a Power BI CFO report, and a live Streamlit ML dashboard deployed on Streamlit Cloud with Supabase (Canada Central) as the cloud database.

The Power BI dashboard includes four pages: an Executive Summary with revenue trends and department expense breakdown, a Revenue and Expenses deep dive with year-over-year comparison matrix, a Budget vs Actual page with variance heatmap and waterfall chart, and a Drill-Through Detail page triggered by right-clicking any department — showing every transaction with category and vendor breakdown. All 13 DAX measures use time intelligence functions including TOTALYTD, SAMEPERIODLASTYEAR, and PREVIOUSMONTH.

The ML layer includes three production models: a Prophet revenue forecasting model (MAPE 9.6%, additive seasonality chosen after diagnosing zero-prediction failures with multiplicative mode), an Isolation Forest anomaly detection model with 8 domain-informed features achieving 68% precision and 78% recall without any labelled training data (vendor names deliberately excluded to prevent data leakage), and an XGBoost budget overrun classifier with 6 mid-quarter features achieving AUC-ROC 0.94 on cross-validation with SHAP waterfall explainability for each department. The Streamlit dashboard surfaces all three models live with interactive controls — including an anomaly score threshold slider and a forecast horizon selector. GitHub Actions CI/CD runs 18 automated tests on every push with a green badge on the README.
